ITSA 2024/2025 初賽

前端零基礎教學簡報

目標：讓不會前端的學生也能完成比賽題

教學核心：題目拆解步驟 = 簡報播放順序

這份簡報怎麼教

每張投影片只教一件事：先看需求，再做最小可行版本。

每個題目都走同一套路：版面 -> 互動 -> 資料 -> 驗收。

每段都有可交作業點：避免最後 20 分鐘才發現不能交。

老師操作：一頁講解 + 一頁示範 + 一頁學生跟做

2024/2025 初賽題型地圖

2024：RWD 切版、前端 CRUD、PHP + MySQL 系統

2025：計算機、聊天框、RWD 登入、產品管理系統

共同能力：HTML/CSS、JavaScript 事件、表單、CRUD 思維

結論：不是要會很多框架，而是要會「拆題與交付順序」。

統一解題流程（7 步）

  1. 讀評分點，圈出「有分數的功能」。
  2. 先做骨架 HTML（可看到版面）。
  3. 補 CSS（先桌機，再 RWD）。
  4. 補 JS 互動（按鈕、切換、送出）。
  5. 有資料就做 CRUD（先 C/R，再 U/D）。
  6. 逐項自測（對照題目分點）。
  7. 命名、路徑、截圖、打包上傳。

步驟 1：讀評分點

把題目轉成待辦清單，格式固定：

[分數] [功能] [驗收條件] [檔名]

新手常錯：直接寫程式，卻漏掉「命名規則」和「上傳路徑」。

步驟 2：骨架先行

先做可見結構：

header / nav / main / section / footer

先不美化，先讓評審「看得見你有做」。

步驟 3：CSS 與 RWD

固定做法：

桌機版完成 -> @media (max-width: 900/768/750px)

每做完一段就縮放瀏覽器檢查。

步驟 4~7：互動、CRUD、驗收、打包

  • 事件綁定：點擊、輸入、Enter 鍵、上傳檔案。
  • CRUD：先把資料顯示出來，再加新增/刪除/更新。
  • 驗收：每個子題至少跑一次示範。
  • 交付：檔名、相對路徑、截圖不可漏。

2024 題一（RWD 首頁）教學拆解

  1. 先切 3 區：導覽列、頁首、內容區。
  2. 做桌機寬版（>900px）等寬與交疊效果。
  3. 做中尺寸（>750px）滿版。
  4. 做小尺寸（<750px）單欄堆疊。

2024 題二（圖書管理）教學拆解

最小可行版本順序：

新增書籍 -> 顯示列表 -> 刪除 -> 更新

用陣列暫存資料即可，不要一開始就追求複雜 UI。

2024 題二：帶著做 01（先做骨架）

本頁完成目標：畫面上要看得到「輸入區 + 列表區」。

學生跟做：建立 form、三個輸入欄位、一個新增按鈕、一個列表容器。

  • 欄位：書名、作者、出版年份。
  • 列表先放假資料 1 筆，確認版型完成。
  • 先不寫刪除/更新功能。

2024 題二：帶著做 02（新增 + 顯示）

本頁完成目標：按下新增，列表會出現新書。

老師口令：「資料先進陣列，再呼叫 render() 重畫列表」。

  • 先做空值檢查（任一欄空白就 return）。
  • 資料格式固定：{ title, author, year }。
  • 每次新增成功後，清空輸入框。

2024 題二：帶著做 03（刪除功能）

本頁完成目標：每筆資料旁都有刪除按鈕，按下可移除。

老師口令：「按鈕帶 index，刪完就重畫。」

  • 列表每筆都產生 刪除 按鈕。
  • 刪除邏輯：books.splice(index, 1)。
  • 刪除後再次呼叫 render()。

2024 題二：帶著做 04（更新功能）

本頁完成目標：點更新後可改書名/作者/年份並存回列表。

建議作法：先把資料帶回輸入欄，再按「儲存更新」。

  • 使用 editingIndex 記錄目前編輯哪一筆。
  • 新增模式與更新模式共用同一顆按鈕。
  • 更新成功後把 editingIndex 重設為 -1。

2024 題二：帶著做 05（課堂驗收）

3 分鐘驗收清單：

新增 1 筆 -> 再新增 1 筆 -> 刪掉第 1 筆 -> 更新剩下那筆

  • 畫面是否立即更新（不用重整頁面）。
  • 年份是否只接受數字。
  • 檔名是否符合題目要求（例如 team021.html）。

這 5 頁做完，題二基本分就穩了。

2024 題二：老師示範程式骨架（精簡版）


const books = [];
let editingIndex = -1;

function render() {
  // 1. 清空列表容器
  // 2. books.forEach(...) 產生每筆資料 + 刪除/更新按鈕
}

function submitBook() {
  const book = readForm(); // { title, author, year }
  if (!book.title || !book.author || !book.year) return;

  if (editingIndex === -1) books.push(book);
  else books[editingIndex] = book;

  editingIndex = -1;
  clearForm();
  render();
}

function removeBook(index) { books.splice(index, 1); render(); }
function editBook(index) { fillForm(books[index]); editingIndex = index; }

講法：先講資料流（讀表單 -> 改陣列 -> render），再補每個函式內容。

2024 題三（健康度量）教學拆解

  • 先畫資料表：人員、醫檢項目、檢查結果。
  • 先做登入流程，再做角色功能（醫檢員/受檢者）。
  • 先完成查詢，再補新增/刪除/更新。
  • 最後補密碼規則與首次登入改密碼。

難點在「流程完整」，不是單一頁面漂亮。

2025 初賽題目拆解

題目 1：計算機、題目 2：聊天框、題目 3：RWD 登入、題目 4：產品管理

2025 題一（計算機）教學拆解

  1. 先做按鈕與顯示區 UI。
  2. 按下按鈕可即時顯示字串。
  3. 按 = 計算（先基本四則，再先乘除後加減）。
  4. 按 C 清空。

2025 題二（聊天框）教學拆解

  • 兩種送出：傳送鍵與 Enter。
  • 送出後清空輸入框，並自動捲到底。
  • 圖片上傳限制：jpg/jpeg/png、<= 5MB。
  • 固定回覆：文字回「已收到訊息！」、圖片回「已收到圖片！」。

重點：事件與條件判斷，不需要真的串 AI。

2025 題三（RWD 會員登入）教學拆解

  1. 做主畫面（左上選單、右上登入）。
  2. 做側欄開合與 transition。
  3. 做登入彈窗與關閉按鈕。
  4. 補 RWD 版本（圖 3-5 到 3-8）。

2025 題四（產品管理）教學拆解

  • 先建 DB 與資料表，再連線 PHP。
  • 先做「檢視商品」讀取資料。
  • 再做新增、刪除、編輯更新。
  • 最後做 <768px 側邊欄隱藏。

給零基礎學生的教學節奏

第 1 段（20 分） 題目翻譯成 TODO + 評分對照表

第 2 段（35 分） 版面骨架與 RWD

第 3 段（35 分） JS 互動與 CRUD

第 4 段（20 分） 測試、截圖、命名、打包

每段結尾都要有「可提交版本」。

簡報與教學綁定規則

  1. 老師只照簡報順序教，不跳步。
  2. 每一頁都要有「這頁完成產出」。
  3. 學生跟做完一頁就存檔一次。
  4. 每三頁進行一次 3 分鐘驗收。

這樣學生即使不熟前端，也能穩定拿到基本分。

結語：先拿穩定分，再衝加分

  • 先完成每題的核心流程（可操作 + 可驗收）。
  • 再補動畫、細節、視覺一致性。
  • 最後 10 分鐘只做交付檢查，不再大改程式。
